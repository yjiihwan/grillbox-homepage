GRILLBOX 관리자

관리자 계정 설정 개발 담당자용

관리자 아이디·비밀번호를 새로 정하고, 저장 권한(GitHub 토큰)을 그 비밀번호로 봉인해 admin/auth.json을 만듭니다. 토큰과 비밀번호는 이 화면 밖으로 전송되지 않으며, 저장소에는 암호문만 들어갑니다.

1. 저장 권한 토큰

GitHub → Settings → Developer settings → Fine-grained tokens → 저장소 grillbox-homepage만 선택 → Permissions에서 Contents: Read and write. 만료는 1년 권장(만료 시 이 화면에서 다시 봉인).

2. 새 아이디 · 비밀번호

비밀번호는 무작위 20자 이상을 권장합니다. 운영자에게 안전한 경로로 전달하고, 여기 외에는 기록하지 마세요.

3. 봉인 파일 만들기

만든 파일을 저장소의 admin/auth.json에 덮어쓰면 다음 로그인부터 새 계정이 적용됩니다.


  


  

    
명령줄로 하려면

    
gh auth token | node tools/seal_auth.mjs grillbox - -     # 비밀번호 무작위 생성
node tools/seal_auth.mjs grillbox '비밀번호' token.txt     # 지정 비밀번호
